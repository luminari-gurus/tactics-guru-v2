# Proposal

## Why

The battle log shows a single list, so important damage, healing and status outcomes can be hard to find during a busy encounter. Issue #404 adds the original game's filters and an explicit Hide action to the current battle dialog.

## What Changes

- Show All, Actions, Damage & Healing, and Status & Saves filters over the existing recent battle history.
- Let players hide and reopen the log from the same battle while preserving order and focus return.

## Capabilities

### Modified Capabilities

- battle-controls gains an in-battle log filter and dismissal requirement.

## Impact

The shared battle HUD and dialog use the existing battle event types. Issue #179 owns round grouping and export.
