and the configured base. No rule matches HTML, fixed-name images/audio, saves or APIs.
No dashboard changes, production deployment, merge or release tag are proposed.

Implementation addition inside the existing build-only Vite plugin:

    generateBundle(_options, bundle) {
      const root = new URL(base, 'https://build.invalid').pathname;
      const paths = Object.values(bundle)
        .map(file => file.fileName)
        .filter(file => /^assets\/.+-[\w-]{8}\.(?:js|css)$/.test(file));
      this.emitFile({ type: 'asset', fileName: '_headers', source: paths
        .map(file => `${root}${file}\n  Cache-Control: public, max-age=31536000, immutable\n`)
        .join('\n') });
    },
