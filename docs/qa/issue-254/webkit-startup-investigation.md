# WebKit dungeon startup investigation (in progress)

## Original failure

[Run 41344487694](https://github.com/luminari-gurus/tactics-guru-v2/actions/runs/41344487694), source `f44a94d1394db8d641d479813d1c476cca4d63d1`, failed only desktop WebKit's `stairs travel once per entry with compass, stay on arrival and restore, and respect locks` in the WebKit stage: 101 passed, one failed, no retries/skips. The error occurred at the `continueSavedDungeon` helper during a later `load()` in the locked-stair loop, after the arrival screenshot had been taken. `page.reload()` had returned, but for 60 seconds `#dungeon-screen` was absent. The accessibility snapshot showed the unmodified HTML shell and `Loading`; no trace, page error or failed-request record was retained. The 171-pass/6-skip Chromium stage is separate. [Original artifact](https://github.com/luminari-gurus/tactics-guru-v2/actions/runs/41344487694/artifacts/13101374378) expires after 30 days.

A [prior main-menu qualification](https://github.com/luminari-gurus/tactics-guru-v2/blob/78a3f75b18601d12e243f810c0cbd1b95154efe9/docs/qa/issue-153/README.md) at `9b543cb` recorded a similar 60-second missing-screen timeout for desktop WebKit's WASD stair case. This is a different source and case; similarity alone does not establish a common cause.

## Ordered-workload follow-up

[Run 41380346497](https://github.com/luminari-gurus/tactics-guru-v2/actions/runs/41380346497), `623afe9`, completed the full Chromium selection before WebKit. Chromium had 170 passes, six skips and one Shaman journey timeout; WebKit had 98 passes, one landscape Shaman/guardian journey failure and three unexecuted cases after stop-on-first-failure. The compass case passed. The WebKit failure was again `undefined is not an object (evaluating ... __DEFAULT ... glTexture)` immediately after a goto/reload pair, with a later ready screen. [Artifact](https://github.com/luminari-gurus/tactics-guru-v2/actions/runs/41380346497/artifacts/13114292392) retains reports and traces. These two Phaser errors occurred after the dungeon module began and are not shown to cause the original missing-screen failure.

The diagnostic source adds three temporary performance markers to the failed PR's product source and bounded page event listeners to tests; that instrumentation can alter timing and is not a fix. A local deliberate failure confirmed that page errors are attached even when the test body succeeds. [Run 41383717758](https://github.com/luminari-gurus/tactics-guru-v2/actions/runs/41383717758) is the replacement 50-case compass probe, retaining errors separately from the event buffer and stopping at the first failure.
